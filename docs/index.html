The greet service,
built in ten chapters.greet 服务，
分十章搭起来。

Every chapter adds one capability to the same running service. By the last one it answers over HTTP, GraphQL and gRPC, keeps its rows in SQLite, and carries tests that go red when any of that stops being true.每章给同一个在跑的服务加一件事。到最后一章，它同时通过 HTTP、GraphQL 和 gRPC 回答，把行存进 SQLite，并带着测试：其中任何一处失效，测试就会红。

x-request-id is the middleware from chapter 1. server: mooncat is the transport signing its own work. The body is a row moonsqlite returned and moonorm decoded, on a connection the process opened at boot.x-request-id 是第 1 章那个中间件加的。server: mooncat 是传输层写下的名字。正文是 moonsqlite 返回、moonorm 解码出来的一行，走的是进程启动时打开的那条连接。

01the stack技术栈

Nine libraries, one request九个库，一次请求

in the order the request meets them按请求经过的顺序

Each line is one library doing one thing to the same request, and any of them can be swapped without the others noticing. The numbers match the transcript in chapter 8.每一行是一个库对同一个请求做的一件事，换掉其中任何一个，别的都不必改。编号与第 8 章那份回放对得上。

  1. 01moonctlReads the .api spec into routes and types.把 .api 描述读成路由与类型。service greet · 1 route
  2. 02moonasgiCarries the request value every layer passes around.传那个各层共用的请求值。GET /users/1
  3. 03moonzeroWraps the routes in a service and logs the call.把路由装进服务，并记下这次调用。x-request-id: greet-1
  4. 04moonapiMatches the path, binds id, builds the body.匹配路径、绑定 id、拼出响应体。200 · 21 bytes
  5. 05moonormBuilds the statement and decodes the row it gets back.拼出语句，并把回来的行解码。SELECT … WHERE id = ?
  6. 06mooncatWrites the bytes to the socket.把字节写到 socket 上。server: mooncat
  7. 07moongqlAnswers the same data as a GraphQL field on the same app.在同一个应用上把同样的数据作为 GraphQL 字段回答。{ greeting(name: "Ada") }
  8. 08moonrpcServes the same greeting over HTTP/2 cleartext.把同一句问候通过 h2c 提供出去。SayHello · 23 octets
  9. 09moonmuseAsks a model through a template and a provider.通过模板与提供者去问一个模型。no key, no network

The chapters课程目录

eight written, two to come已写八章，还有两章
  1. 01A service is a function服务就是一个函数Three routes, one middleware, one real port. The smallest thing that answers.三条路由、一个中间件、一个真实端口。先把最小的服务跑起来。moonasgi · moonapi · mooncat
  2. 02One spec, one model一份描述，一个模型Describe the data once; a generator writes the model the service persists through, and the build proves it has not drifted.数据只描述一次，模型由生成器写出，构建会证明它没有漂移。moonctl · moonorm
  3. 03Rows and sessions行与会话Write a row with a bound parameter, read it back through the generated model, and do the same through two other descriptions of the table.用绑定参数写一行，用生成的模型读回来，再用另外两种表的描述各读一遍。moonorm · moondb · moonsqlite
  4. 04A second surface第二个门面The same routes published as an OpenAPI document, and a GraphQL field mounted on the very same application.同一批路由既是 OpenAPI 文档，也是同一个应用上挂的 GraphQL 字段。moonapi · moongql
  5. 05A third surface第三个门面greet.Greeter over HTTP/2 cleartext with Server Reflection, so a client can discover the service before it calls.greet.Greeter 跑在 h2c 上并带 Server Reflection，客户端可以先发现服务、再调用。moonrpc
  6. 06Assembly装配Wrap the routed application in a service: configuration, the middleware chain, one access log line per call.把路由装进服务：配置、中间件链、每次调用一行访问日志。moonzero
  7. 07Stopping well好好停下Hooks in reverse order, a connection drained behind a GOAWAY, and a run that waits at a node for an answer.钩子倒序执行、连接用 GOAWAY 排空、图停在某个节点等人回答。moonstate · moonrpc
  8. 08The whole stack, once全家桶，一次走完Nine libraries, one greeting, no socket: what each layer contributes, in one program.九个库、一句问候、不开端口：一次性看清每一层各自做了什么。nine-in-one
  9. 09The production edges生产环境的边角What a service needs once it works: tokens, validated bodies, pagination, a transaction, background work, a stream, metrics.服务能跑之后还缺的东西：令牌、校验、分页、事务、后台任务、流、指标。moonapi · moonmcp · moonp8s
  10. 10The map地图Where every library sits, which one to reach for next, and how to add a layer without touching the ones below.每个库站在哪一层、下一个该读谁、怎么加一层而不动下面。reference
