Three parts to a chapter每章三段

Run it, read the code behind the output, then change something yourself.先跑起来，再读输出背后的代码，最后自己改一处。

One idea, three spellings同一件事，三种说法

Where a library offers more than one, the code block switches between writing it, letting your types carry it, and letting annotations generate the glue.库有多种写法的地方，代码块可以在三者之间切换：自己写、交给类型、交给注解。
