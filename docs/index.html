01the stack技术栈

Nine libraries, one request九个库，一次请求

in the order the request meets them按请求经过的顺序

Each line is one library doing one thing to the same request, and any of them can be swapped without the others noticing. The numbers match the transcript in chapter 8.每行只做一件事；换掉任何一个库，其余都不用改。编号与第 8 章的回放对得上。

  1. 01moonctlReads the .api spec into routes and types.把 .api 描述读成路由与类型。service greet · 1 route
  2. 02moonasgiCarries the request value that every layer shares.在各层之间传递同一个请求值。GET /users/1
  3. 03moonzeroWraps the routes in a service and logs the call.把路由装进服务，并记下这次调用。x-request-id: greet-1
  4. 04moonapiMatches the path, binds id, builds the body.匹配路径、绑定 id、拼出响应体。200 · 21 bytes
  5. 05moonormBuilds the statement, then decodes the row it gets back.拼出 SQL，再把查回的行解码成记录。SELECT … WHERE id = ?
  6. 06mooncatWrites the bytes to the socket.把字节写到 socket 上。server: mooncat
  7. 07moongqlAnswers the same data as a GraphQL field on the same app.同一个应用上，用 GraphQL 字段回答同一份数据。{ greeting(name: "Ada") }
  8. 08moonrpcServes the same greeting over HTTP/2 cleartext.同一句问候，再走一遍 h2c。SayHello · 23 octets
  9. 09moonmuseAsks a model, through a template and a provider.用模板和提供者调用模型。no key, no network
02setup准备

Before you start开始之前

the toolchain, the code, one run工具链、代码、跑一次

The service is a native program: it listens on a port and links SQLite. You need the MoonBit toolchain and a C compiler — gcc or clang, or Visual Studio's on Windows.这个服务是原生程序：它监听端口，并链接 SQLite。要装好 MoonBit 工具链和一个 C 编译器：gcc 或 clang，Windows 上用 Visual Studio 自带的。

shell
# the toolchain: Linux and macOS, then Windows in PowerShell
$ curl -fsSL https://cli.moonbitlang.com/install/unix.sh | bash
> irm https://cli.moonbitlang.com/install/powershell.ps1 | iex

# the code, its tests, and the service on port 12000
$ git clone https://github.com/moonbitstack/moonhelo
$ cd moonhelo
$ moon test --target native
$ moon run src/cmd/greet-server --target native

# from a second terminal
$ curl -s localhost:12000/ping
pong

Chapter 01 starts from this running service and takes it apart.第 01 章就从这个跑起来的服务讲起，一层一层拆开看。

03styles写法

Three ways to write it三种写法

pick one, every page follows选一次，各章都照此显示

Where a library offers more than one shape for the same thing, the sample shows each, with tabs above it. All three stay, because each suits a different size of service.同一件事库里有几种写法时，示例把每种都列出来，用上方的页签切换。三种写法都保留，是因为它们各适合不同规模的服务。

  1. 01Function函数Routes are calls on an app value, each handler next to its path. Start here: nothing to learn before the first route.路由就是在应用值上的调用，处理函数紧挨着它的路径。从这里起步，写第一条路由前不用先学别的。app.get("/ping", …)
  2. 02Types类型A route is a value that answers its path, so it can hold a connection or a cache for as long as it lives.路由是一个能应答路径的值，所以它能在存活期间一直持有连接或缓存。impl @moonapi.View for Greeter
  3. 03Annotations注解#app.get and #orm.table on plain functions and structs; the generator writes the registration and the model, which keeps forty routes readable.在普通函数和结构体上写 #app.get、#orm.table，注册代码和模型由生成器写出，路由到了四十条也照样好读。#app.get("/ping")
  4. 04From a spec描述生成Not a tab but a road through the whole course: one .api file, from which moonctl generates the routes, the types and the model. Chapter 02.不是页签，而是贯穿全书的一条路：一份 .api 文件，moonctl 据此生成路由、类型和模型。见第 02 章。greet.api

04contents目录

The chapters课程目录

all ten, end to end十章，走完一遍
  1. 01A service is a function服务就是一个函数Three routes, one middleware, one real port. The smallest thing that answers.三条路由、一个中间件、一个真实端口。先把最小的服务跑起来。moonasgi · moonapi · mooncat
  2. 02One spec, one model一份描述，一个模型Describe the data once; a generator writes the model the service persists through, and the build proves the two agree.数据只写一遍，模型交给生成器；两者是否一致，由构建来保证。moonctl · moonorm
  3. 03Rows and sessions行与会话Write a row with a bound parameter, read it back through the generated model, then read it again through two other descriptions of the same table.用绑定参数写一行，用生成的模型读回来，再用另外两种表定义各读一遍。moonorm · moondb · moonsqlite
  4. 04A second surface第二个入口The same routes published as an OpenAPI document, and a GraphQL field mounted on the very same application.同一批路由既是 OpenAPI 文档，也是同一个应用上挂的 GraphQL 字段。moonapi · moongql
  5. 05A third surface第三个入口greet.Greeter over HTTP/2 cleartext with Server Reflection, so a client can find the service before it calls it.greet.Greeter 走 h2c，带 Server Reflection，客户端可以先发现、再调用。moonrpc
  6. 06Assembly装配Wrap the routed application in a service: configuration, the middleware chain, one access log line per call.把路由装进服务：配置、中间件链、每次调用一行访问日志。moonzero
  7. 07Stopping well优雅停下Hooks in reverse order, a connection drained behind a GOAWAY, and a run that waits at a node for an answer.钩子倒序执行、连接用 GOAWAY 排空、图停在某个节点等人回答。moonstate · moonrpc
  8. 08The whole stack, once全家桶，一次走完Nine libraries, one greeting, no socket: what each layer contributes, in one program.九个库、一句问候、不开端口：一次性看清每一层各自做了什么。nine-in-one
  9. 09What production adds上生产还缺什么What a service needs once it works: tokens, validated bodies, pagination, a transaction, background work, a stream, metrics.服务能跑之后还缺的东西：令牌、校验、分页、事务、后台任务、流、指标。moonapi · moonzero · moonp8s
  10. 10The map地图Where every library sits, which one to reach for next, and how to add a layer without touching the ones below.每个库在哪一层、接下来该看哪个、加一层怎样不惊动下面。reference
