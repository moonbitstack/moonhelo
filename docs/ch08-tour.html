Chapter 08第 08 章

The whole stack, once全家桶，一次走完

Nine libraries, one greeting, no socket and no database. Each layer contributes a line to the output, and reading the nine lines in order is the shortest tour of what the stack is.九个库、一句问候、不开端口、不连数据库。每一层在输出里贡献一行，按顺序读完这九行，就是这一栈最短的导览。

01Run it跑起来

One program, everything in process. It is the chapter you can hand to someone who has ten minutes and wants to know what this family of libraries is for.一个程序，全部在进程内。这一章适合交给只有十分钟、又想知道这一族库到底做什么的人。

shell
$ moon run src/examples/00-nine-in-one --target native
moonctl : parsed service 'greet' — 1 route, 1 type
moonasgi: scope GET /api/v1/greet/heke1228
moonzero: group /api/v1 mounted the route
moonapi : 200 Bonjour, heke1228!
moonapi : 200 then 304 — 0 octets the second time
mooncat : would serve on http://127.0.0.1:12000
moonorm : SELECT id, name FROM greets WHERE name = ?
moonrpc : gRPC message 23 octets
moongql : {"data":{"greet":"Bonjour, heke1228!"}}
moonmuse: prompt 'Greet heke1228 in one sentence.'
moonmuse: Bonjour, heke1228!

02Line by line逐行看

Eleven lines, nine libraries, and one of them speaks twice because a conditional request is answered twice.十一行、九个库；其中一个说了两次，因为一次条件请求被回答了两次。

03What this proves这证明了什么

That the layers are separable. Nothing here needed a port, a database file or an API key, because each library exposes a value you can build and hand to the next one by hand.各层是可分的。这里不需要端口、数据库文件或 API 密钥，因为每个库都暴露一个可构造的值，你可以手动交给下一个。

Where the demo is thinner than the service这个演示比真实服务薄的地方
The nine-in-one program stops at the seam where a real deployment would keep going: the SQL is built but not executed, the gRPC message is encoded but not sent, the prompt is answered by a scripted provider. Chapters 1 to 7 are the parts that do run.全家桶停在真实部署会继续往前走的那条缝上：SQL 拼出来但没执行，gRPC 消息编好但没发出去，提示词由脚本化提供者作答。真正跑起来的部分在第 1 到第 7 章。

Read it as a map rather than a demo. Every line names the library that produced it, which is the whole reason it exists.把它当地图读，而不是当演示。每一行都点出了产出它的库 —— 这正是它存在的全部理由。

Two changes两处改动

  1. Delete one of the nine blocks and run it again. The program still builds, and the output loses exactly one line — the layers do not depend on each other in the order you expect.删掉九块里的一块再跑。程序照样能编，输出只少一行 —— 各层之间的依赖并不像你预期的那样成链。
  2. Change who and read which lines move. The spec does not; everything downstream does.改掉 who，看哪几行动了。spec 不动，下游全动。

You can now你现在会了

  • Name the library behind each line of the output.说出输出里每一行背后是哪个库。
  • Explain what one request passes through, in order.按顺序说出一次请求经过了什么。
  • Say which parts of the demo would need a socket, a file or a key to become real.说出演示里哪些部分要变成真的需要端口、文件或密钥。
  • Use the program as a map when you forget which library does what.忘记哪个库干什么时，把这个程序当地图用。
